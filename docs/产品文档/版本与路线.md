# 版本与路线

应用版本、协议版本、词典版本和数据库格式是不同的编号，不要求相等。

| 部分                     | 当前范围                      | 状态与边界                                          |
| ------------------------ | ----------------------------- | --------------------------------------------------- |
| Desktop / Core / Browser | 1.0.0                         | 本机学习与本地连接；最终发行物以各仓库 Release 为准 |
| LMCP                     | API 1.0.0                     | 本地连接合同；16 必需、3 可选方法                   |
| Dictionary               | 0.0.3                         | 已发布固定词包；客户端按清单校验                    |
| 学习规则                 | `leximeet.learning/2`         | 0–30 分、阶段与 FSRS 分离                           |
| 个人数据库               | schema 100                    | 当前结构；不是 Dictionary 版本                      |
| LMSP                     | 目标 API 1.0.0，rc.4 合同基线 | 属于应用 2.0.0；真实云同步尚未交付                  |

## 正式 1.0.0：本机闭环

- 六种练习、可选规划、词卡、语境、笔记、单词本和回收恢复。
- 默认安全采集、七天去重、桌面目标内剪贴板识别。
- 浏览器独立运行，或通过用户确认连接桌面；临时失联不改变归属。
- 首装、七天日常使用、真实连接与同结构候选替换测试。

Desktop、Core、Browser 与 LMCP 的首次正式版本及标签均为 `1.0.0`，Browser 包含在这组发布范围内。发布还需要核对远端CI、分发平台、签名/公证、完整许可和实际安装环境；本地标签或检查成功不代表商店已上架。操作步骤见[发布与版本管理](../开发文档/发布与版本管理.md)。

Core 与 Browser 已实现正式 1.x 的版本与能力协商：主版本、最低 API 与必需能力决定是否可连接；预发布候选仍要求同版同摘要。分支回归和当前冻结组合验收不能替代未来版本、平台的真实互操作验收。

## 2.0.0：独立设备云同步

Desktop 与独立 Browser 是平等设备；用户主动点击同步。首次同步选择云覆盖或合并，合并中的普通资料采用云优先；练习和遇见事件按稳定身份合流，不相加最终分数。

历史资料首次上传时，按最近三天、三至七天和更早的记录分批处理，再按字节分页、补齐依赖并保存检查点。即使资源版本不同，也要保留私人事实；显示与出题使用双方可用资源的交集，缺少公共词卡时不能删除笔记或语境。

Browser 连接桌面后，不再使用自己的账号或云 outbox，当前工作区由桌面负责。LMSP 仍需真实云端、两个独立设备、离线冲突和正式 1.0.0 资料首次同步验收。

## 保留的后续方向

| 方向                                | 完成前要验证什么                                |
| ----------------------------------- | ----------------------------------------------- |
| Windows/Linux、更多 Chromium 浏览器 | 安装、Host 注册、通知输入、打包 JRE、升级与权限 |
| IDEA / VS Code / WPS 等插件         | 宿主真实能力、单项权限和不修改原文的交互        |
| 可访问性                            | VoiceOver/NVDA、缩放、对比度与减少动画          |
| 翻译或 AI 服务                      | 用户启用、密钥隔离、来源、超时与费用边界        |
| 词典学习内容                        | 缺失助记、非核心学习内容、录音与来源许可        |

正式1.0.0开始维护真实用户资料的版本升级承诺。首发前的0.x/rc测试库不做迁移，也不自动删除；后续1.x升级必须保护正式资料。
