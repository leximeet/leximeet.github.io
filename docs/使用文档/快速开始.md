# 快速开始

词遇可以从桌面或浏览器开始。先用一份隔离资料体验教学、记录和练习，再决定长期使用方式。

想按图操作：看[桌面端步骤演示](桌面端.md)或[浏览器阅读与练习演示](浏览器插件.md)。截图可点击放大，浏览器阅读图同时显示网页正文与原生侧栏。

## 桌面端

从 Desktop 仓库（[GitHub](https://github.com/leximeet/leximeet-desktop) / [Gitee](https://gitee.com/leximeet/leximeet-desktop)）的可信发行记录选择适合本机的发行包；没有正式发行物时，请自行构建，不使用来源不明的安装器。

GitHub 与 Gitee 是平级入口；每个平台是否已有安装包，以实际发行记录为准。相同版本应对应相同源码和 SHA-256，不混用来源不同的同名包。

开发体验使用仓库的一键脚本：

```bash
# 任选同一仓库的一个平台地址
git clone --recurse-submodules https://github.com/leximeet/leximeet-desktop.git
# git clone --recurse-submodules https://gitee.com/leximeet/leximeet-desktop.git
cd leximeet-desktop
bash scripts/test-desktop.sh
```

脚本准备可用 Node、JDK 21、Maven 与固定词包，创建独立测试空间。macOS 使用独立验收应用与通知身份，不修改日常资料。首次下载需要网络和磁盘空间。

首次打开时，可以进入或跳过教学。你可以在「学习规划」选择目标与计划，也可以暂不设置，直接到练习中心自由练习。[桌面使用](桌面端.md)

## 浏览器独立端

从 Browser 仓库（[GitHub](https://github.com/leximeet/leximeet-browser) / [Gitee](https://gitee.com/leximeet/leximeet-browser)）的可信发行物取得解压后的扩展，或按仓库指南构建。

打开 Chrome 扩展管理页，开启开发者模式，加载 `.output/chrome-mv3/`。当前要求 Chromium 142+；这是解压加载流程，不代表已发布到扩展商店。首次安装后会打开扩展自带的教学。[浏览器使用](浏览器插件.md)

开发者可以运行 `npm run lab:browser`，使用专属 Chromium 与新 profile 体验。没有网络时，可用 `LEXIMEET_LAB_URL=local npm run lab:browser` 阅读本地测试文章。

## 两端一起体验

准备[目录布局](../开发文档/环境与联调.md)后，从 Desktop 执行：

```bash
bash scripts/test-desktop.sh --connected
```

在任一端点击「一键连接」，再到浏览器独立确认窗口接受。连接只切换活动资料来源，不合并独立历史。先读[连接与断开](插件连接.md)。

::: warning 测试资料与个人资料
隔离脚本创建临时体验空间，不适合作为长期个人资料库。`npm start` 指向正式本机资料，不用于首装测试；不要通过删除数据库排查问题。
:::

完整环境与平台限制见 [Desktop 本地启动说明](https://github.com/leximeet/leximeet-desktop/blob/main/docs/本地测试启动.md)和 [Browser 开发指南](https://github.com/leximeet/leximeet-browser/blob/main/docs/开发指南.md)。
