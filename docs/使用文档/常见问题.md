# 常见问题

## 必须设置学习规划吗？

不需要。可以只记录、整理和自由练习；学习规划用于建议安排目标新词与每日数量。

## 为什么连接后原浏览器单词不见了？

原资料 A 已在本机封存，连接期间显示的是 Desktop 的资料 B。明确断开后会恢复 A；连接期间新增的 C 留在桌面，不会自动带回浏览器。[图解](插件连接.md)

## 桌面退出后为什么没有切回独立模式？

短暂失联不等于明确断开。自动切回会让一次采集落到两份不同资料，所以插件等待恢复或用户明确断开。

## 复制英文却没有通知？

检查剪贴板识别是否开启、是否有当前目标、词是否命中目标，以及系统通知许可。相同安全语境七天内不重复提醒；目标外词请用插件或手动记录。[采集说明](采集与隐私.md)

## 为什么答对却没有增加复习完成量？

临摹、提示后订正、同题首错后的订正、毕业当天或熟悉休息期不算有效复习完成。同词今天已完成，也不会再次增加词数。已有复习资格的词，首次独立作答成功后，即使 FSRS 尚未到期也会计入完成量。

## 练习提示保存未确认怎么办？

使用原题「重试保存」或结果恢复入口，保留原提交身份。不要通过重开、重复点击或新编号把未知结果当成失败；确认后可以正常重开。没有真实题目时换模式或下一词。

## 没有通知练习是什么原因？

Desktop 只有在计划与提醒均开启、有任务、处于提醒时间范围内且应用不在前台时，才会发送练习通知。默认随机等待 25–35 分钟；权限不足或本 OS 不支持时不伪造成功。普通练习随时可用。

## 发音失败怎么办？

检查网络、所选 Provider 和自定义地址。Browser 不支持带私密凭据的音频模板；Desktop 密钥在本设备保存。文本词典无需在线发音也能使用。

## 可以导入旧测试库或使用云同步吗？

1.0.0 不转换未发布 0.x/rc 资料；未知格式保留并拒绝打开。当前没有个人导入导出、账号和云同步。使用新的隔离测试空间，正式资料升级与云同步属于后续已发布版本的承诺。

遇到其他问题，请在对应仓库提交最小复现，附版本、OS、入口和安全错误信息，不上传完整数据库、凭据或私人语境。见[贡献指南](../开发文档/贡献指南.md)。
