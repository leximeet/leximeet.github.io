# 隐私与许可

个人资料本机优先；词遇 1.0.0 不提供账号、云同步或遥测上传。本站也是静态文档站，本地搜索，不接入统计 SDK、远程字体或外部搜索服务。

## 数据会去哪里

| 内容                              | 去向                                                     |
| --------------------------------- | -------------------------------------------------------- |
| 独立 Browser 语境、笔记、学习记录 | 当前浏览器 IndexedDB                                     |
| Desktop 或连接 Browser 的新增     | 本机 Desktop SQLite                                      |
| 公共词包下载                      | 固定 Dictionary Release，校验摘要                        |
| 在线发音                          | 所选服务，默认只发送词头                                 |
| 文档站访问                        | 部署后的托管方负责 HTTP 请求日志；本站不另外上传用户行为 |

默认脱敏无法保证清除所有秘密。安全 Issue、日志和截图请使用合成样例，不要包含 token、Key、完整个人库或原始私人语境。

## 代码与第三方许可分开

词遇自有代码与文档统一采用 **AGPL-3.0-only**，具体以各仓库 LICENSE 为准。Dictionary 数据、音频、字体、图标和第三方依赖保留各自原许可与署名；不能把仓库代码许可写成所有物料的统一许可。

应用包需要保留源码入口、许可全文、第三方声明与对应物料。公共词包使用 release 清单及随包 notice；部分音频和词典层有不同权利条件，修改或再分发前读取具体声明。

文档站构建也保留实际浏览器依赖的第三方许可和自有许可全文，不将 MIT 等第三方代码改成 AGPL。产物中的 `THIRD_PARTY_NOTICES.txt` 与 `LICENSE.txt` 随 Pages 上传；使用系统字体，不分发额外字体文件。

本站使用 VitePress 官方默认主题、Mermaid 和必要图表插件。依赖声明在锁文件中，图片出处在[素材来源](素材来源.md)；不复制私有部署、收费业务、内部日志或工作区讨论。

## 安全报告

在受影响仓库读取 SECURITY。若 GitHub 私密漏洞报告已启用，可使用该渠道；未启用时先向维护者确认私密途径。不要为项目编造邮箱或宣称已有专门响应团队。
