# 功能设计

词遇围绕「遇见 → 留下语境 → 主动回忆 → 安排复习」组织功能。学习规划是可选的：用户可以只记录单词和练习，也可以选择词书，按每日额度学习。浏览器的连接模式把资料管理留给桌面，避免两处同时修改两份权威状态。

## 两条完整的使用路径

```mermaid
flowchart LR
  S[第一次使用] --> P(是否设置规划):::decision
  P -->|暂不设置| W[手动 / 网页采集]
  W --> F[我的词库：自由练习]
  P -->|设置| G[选择目标词书]
  G --> Q[每日新学 / 复习额度]
  Q --> T[今日任务]
  T --> F
  F --> R[状态、学习历史和自动复习]
```

不设置计划，仍可使用词库、笔记和练习。Desktop 剪贴板用于补充目标内单词的语境，因此没有目标时不会提醒；网页和手动采集则允许增加目标外单词。

## 学习规划 = 目标 + 计划

目标表示学哪些词，计划表示每天安排多少；提醒是 Desktop 的设备能力。

| 项目            | 默认或行为                          | 保存边界                              |
| --------------- | ----------------------------------- | ------------------------------------- |
| 学习目标        | 选择公共词书，可预览再确认          | 引用词书，不把整本词典复制成用户词条  |
| 每天新学 / 复习 | 10 / 20                             | 目标与额度原子保存，检查并发 revision |
| 暂停计划        | 停止补充目标新词                    | 目标、进行中学习和既有事实保留        |
| 学习提醒        | 开关 + 08:00–20:00 范围             | 关闭只停通知，不改变分数或复习资格    |
| 提醒模式        | 设置页，默认看词选义，可多选轮换    | 不修改目标、额度或学习历史            |
| 提醒频率        | 范围内随机 25–35 分钟，均值 30 分钟 | 本机节流，不是用户学习事件            |

预览中的天数是按剩余新词和每日新学计算的安排参考，不承诺每天一定完成。切换目标保留已有学习事件；曾完成初学的词不会重新占新学名额。Browser 独立模式遵循同一学习口径，但当前没有 Desktop 的原生单题学习通知。

## 练习中心的六种模式

| 顺序 | 模式     | 用户动作                                            | 独立正确 / 熟练 | 能否证明回忆                               |
| ---: | -------- | --------------------------------------------------- | --------------: | ------------------------------------------ |
|    1 | 单词列表 | 回想后熟练 +1 / 不熟悉 −1，默认遮中文，可切换遮英文 |              +1 | 明确自评可作为调度证据，不混入客观题正确率 |
|    2 | 看词选义 | 选择一项冻结综合释义                                |              +1 | 是                                         |
|    3 | 单词临摹 | 对照英文直接输入                                    |              +1 | 否；不能虚构 FSRS 成功                     |
|    4 | 单词默写 | 看释义独立拼写                                      |              +2 | 是                                         |
|    5 | 听音辨词 | 听发音后作答                                        |              +1 | 是                                         |
|    6 | 语境填空 | 在有效例句中输入目标词                              |              +2 | 是                                         |

错误、不熟悉或练习中查看遮挡答案 −1；最低 0、最高 30。普通词卡阅读、发音和采集不计分。一次拼写错误按提交的一次答案结算，不能每敲错一个字扣一分。同题首次反馈计一次，提示后订正不补分。

题目在显示前先冻结；UI 只提交答案，不提交权威 `correct` 或目标积分。回答提交与导航串行：确认回执后展示反馈，再继续下一词；快速重复点击不能触发额外计分。未确认结果保留原提交 ID 供重试。同范围内各模式分别持有位置和草稿；相同候选词序可以共用，当前模式重开刷新候选而不覆盖其他模式。

「重新开始」创建新会话和题目空间，保留已保存成绩、遇见和笔记，不等于清空学习历史。题目不可用时显示该词与原因；不能沿用上一词的选项或把存储失败伪装为缺词。

## 单词列表和详情

我的词库是当前目标成员与活动手动词的并集。状态 tab 在整个查询范围上筛选，再计数、分页，不是只过滤屏幕上的一页。

- 未学习：没有有效练习；初始 10 分。今日安排的词额外显示待学习。
- 学习中：开始练习、尚未首次达到 20。
- 待复习：曾完成初学、当前不在满分休息期；不等于 FSRS 已到期。
- 已熟悉：到过 30 且休息尚未结束，衰减到 29–21 仍属此类。
- 不熟悉：当前 0 分，可同时属于学习中或待复习。

词卡分公共资料与个人补充：用户笔记不写回公共词典，词典安装也不重建用户资料。遇见记录以单词为标题、较小语境为正文，保留真实句子和来源；同词可以有多个不同语境。

## 提醒与教学

Desktop 提醒提供一道快速练习题，复用同一套冻结题目和学习规则，不另设通知分数。无题、忽略、超时或系统拒绝投递都不扣分；当前 macOS 使用原生通知动作和回复能力，系统权限与声音仍需人工验收。

第一次打开先邀请开始或跳过教学。教学从侧栏开始，随后引导可选规划、练习、发音和主要设置。批注卡支持上一步、跳过和设置页重开；真实操作确认后才推进，发音等播放完成后确认。讲解设置和回收站时不强迫改数据；教学过程中只允许指引动作，窗口边界和高亮留出间距。

## Desktop 词库与预测

目标词是公共引用，回收通过个人标记排除，不改公共词典。恢复纯目标引用不会生成采集记录；当前页多选支持原子回收、恢复和追加到多个单词本。查询在分页前按状态、搜索和真实义项词性过滤；不存在统一重要等级时不提供推测分级。个人编辑只包括笔记与多单词本，冻结字段省略时保持原值。

预测表示目标词的初学完成额度，今日采用真实队列，未来按当前候选顺序预览。它与积分、熟悉状态和 FSRS 到期时间表达不同概念，也不会创建学习事实。实现接口见[Core词库与规划查询](https://github.com/leximeet/leximeet-desktop-core/blob/main/docs/词库与规划查询.md)。
