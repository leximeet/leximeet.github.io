# 词遇文档站

词遇的中文产品、使用、开发与设计文档。站点采用 VitePress 官方默认主题，支持本地搜索、明暗主题和 Mermaid 图解。

使用页提供实际操作步骤和完整阅读工作区截图。图片保持原有正文尺寸，宽图随正文自适应；点击或按 Enter 放大，按 Esc 关闭。手机和明暗主题使用同一套正文。

所有正文都维护在根目录 [docs](docs/index.md)。`website/` 只保存前端配置；构建前会校验并建立 `website/docs → ../docs` 入口，让站点直接使用这份正文。

## 本地启动

需要 Node.js 22.12–25 与 npm。

```bash
npm ci
npm run dev
```

启动后，终端会显示本机访问地址。运行完整检查并预览生产构建：

```bash
npm run verify
npx playwright install chromium
npm run test:dev
npm run test:ui
npm run serve -- --port 4174
```

构建、开发和预览均以 `website` 为 VitePress 根目录，产物统一在 `website/.vitepress/dist`。脚本拒绝覆盖真实目录或指向其他资料的软链接。

## 部署与检查

GitHub Actions 在 push 与 PR 时执行隔离脚本测试、引用检查、格式检查和静态构建，并对真实 dev 冷启动与生产预览运行无头 UI 回归。Pages 部署仅由维护者手动触发，配置见 [维护文档站](docs/开发文档/维护文档站.md)。

文档站不接入遥测、外部字体或云搜索。依赖锁定到稳定 VitePress 1.6.4；将其构建链中的 Vite 固定为含安全修复的 6.4.3，并通过实际构建与页面测试验证兼容性。
